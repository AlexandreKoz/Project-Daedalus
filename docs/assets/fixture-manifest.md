# Controlled fixture corpus

All assets are generated by `tests/assets/generate_fixtures.py`, are self-authored, deterministic, and released under CC0-1.0. Generated outputs are committed so clean-checkout tests do not require Python; rerunning the generator was verified to reproduce them byte-for-byte.

## Valid and intentionally degraded fixtures

- `minimal.glb`: minimal indexed GLB triangle.
- `external_scene.gltf`: external buffer and PNG, interleaved attributes, two primitives/materials/scenes, multiple roots, hierarchy, negative scale, perspective camera, and a punctual light.
- `embedded_image.glb`: GLB geometry plus a buffer-view PNG.
- `data_uri_scene.gltf`: data-URI buffer and PNG images, `KHR_mesh_quantization`, normalized integer normals/tangents/UVs/VEC3 colours, 8-bit indices, broad material metadata, sampler modes, and an orthographic camera.
- `jpeg_image.gltf`: self-authored data-URI baseline JPEG used to exercise JPEG frame/scan/metadata validation without an external fixture dependency.
- `stale_bounds.gltf`: valid geometry with intentionally incorrect accessor `min`/`max`; import succeeds with a visible `bounds_recomputed` repair and uses decoded bounds.

Auxiliary dependencies such as `external_scene.bin`, `texture.png`, and `texture_changed.png` are not standalone top-level fixtures. The changed texture is used to prove dependency-content cache-key invalidation.

## Invalid fixtures

The 18 controlled failures cover malformed JSON, corrupted GLB framing, missing external buffer/image, accessor overrun, invalid stride, out-of-range indices, non-finite attributes, unsupported required extension, unsupported primitive mode, multiple-parent graph, unsupported image encoding, truncated PNG, invalid base64, network URI, path traversal, material factor outside schema range, and quantized accessors without required `KHR_mesh_quantization` declaration.

`tests/assets/manifest.json` is the machine-readable top-level list: 6 valid/degraded and 18 invalid assets.
