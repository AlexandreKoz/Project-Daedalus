# Controlled fixture corpus

All assets are generated by `tests/assets/generate_fixtures.py`, are self-authored, deterministic, and released under CC0-1.0. Generated outputs are committed so clean-checkout tests do not require Python.

`tests/assets/manifest.json` is the machine-readable top-level list. Campaign C contains **26 valid/degraded top-level fixtures and 25 invalid fixtures**.

## Campaign A/B valid and intentionally degraded fixtures

- `minimal.glb`: minimal indexed GLB triangle.
- `external_scene.gltf`: external buffer and PNG, interleaved attributes, two primitives/materials/scenes, multiple roots, hierarchy, negative scale, perspective camera, and a punctual light.
- `embedded_image.glb`: GLB geometry plus a buffer-view PNG.
- `data_uri_scene.gltf`: data-URI buffers/images, `KHR_mesh_quantization`, normalized integer attributes, broad material metadata, sampler modes, and an orthographic camera.
- `jpeg_image.gltf`: self-authored baseline JPEG decode fixture.
- `stale_bounds.gltf`: deliberately stale accessor min/max repaired from decoded geometry.
- `material_default.gltf`: explicit source material 0 plus an omitted material, proving the canonical default sentinel remains distinct.
- `uv1_scene.gltf`: intentionally divergent UV0/UV1 data for explicit texture-coordinate-set validation.
- `instanced_tangents.gltf`: one mesh used by multiple transformed nodes, including negative determinant and tangent signs.
- `repaired_vectors.gltf`: controlled normal/tangent/quaternion repair diagnostics.

Auxiliary dependencies such as `.bin`, PNG, and changed-texture files are not standalone manifest entries.

## Campaign C1 deterministic material fixtures

- `c1_base_color_factor.gltf`: factor-only base colour/alpha behavior.
- `c1_srgb_base_color.gltf`: base-colour texture whose byte values make sRGB treatment observable.
- `c1_metallic_roughness.gltf`: deliberately distinct channels (G != B), proving roughness=G and metallic=B rather than a visually plausible swap.
- `c1_normal_map.gltf`: tangent-space normal texture plus non-default `normalTexture.scale`.
- `c1_tangent_negative_scale.gltf`: source tangent signs plus mirrored node transform for world-determinant handedness.
- `c1_emissive.gltf`: emissive factor and sRGB emissive texture.
- `c1_occlusion.gltf`: distinct RGB values with AO carried only in R plus non-default strength.
- `c1_alpha_modes.gltf`: OPAQUE, MASK below cutoff, MASK above cutoff, and BLEND materials in one deterministic scene.
- `c1_double_sided.gltf`: double-sided material/back-face shading fixture.
- `c1_directional_light.gltf`: canonical `KHR_lights_punctual` directional light orientation.
- `c1_point_light.gltf`: point light with finite range.
- `c1_spot_light.gltf`: spot light with distinct inner/outer cones and finite range.

These fixtures are intentionally small and independent: each is designed to expose one material/light contract rather than hide errors inside a production asset.

## Campaign C2 reference scenes

- `c2_textured_cube.gltf`: six-face textured cube with explicit normals/UVs/tangents and a directional key light; exercises depth, transforms, texture sampling and deterministic camera framing.
- `c2_material_sphere_grid.gltf`: 5x5 self-authored UV-sphere grid spanning metallic 0..1 and perceptual roughness 0.04..1; designed for direct-light and IBL response inspection.
- `c2_pbr_production_asset.gltf`: multi-material production-style controlled assembly with paint, metal, rubber, emissive accent and a spot light.
- `c2_architectural_interior.gltf`: room shell with multiple materials, occluders and directional/point/spot lights for shadow, overdraw, resource and stress validation.

All four are generated from source mathematics/data; no third-party copyrighted model or HDR asset is required.

## Invalid fixtures

The 25 controlled failures cover malformed JSON/GLB framing, missing dependencies, accessor/stride/index errors, non-finite attributes, unsupported requirements/topology/images, malformed graph/URI/base64 inputs, material range errors, invalid quantization declaration, missing UV1, corrupt image entropy, gross invalid vectors, and deterministic resource-budget overflow.

Important audit-closure negatives include:

- `missing_uv1.gltf`: referenced texcoord set absent from the primitive;
- `corrupt_entropy_png.gltf` / `corrupt_entropy_jpeg.gltf`: structurally plausible but invalid image streams;
- `zero_normal.gltf`, `zero_tangent.gltf`, `zero_quaternion.gltf`: invalid zero-length vectors;
- `budget_overflow.gltf`: resource-use boundary rejection.

## Reproducibility procedure

Regenerate into the tracked fixture tree and run the manifest validator against a freshly built asset validator:

```bash
python3 tests/assets/generate_fixtures.py
python3 scripts/validate-fixture-manifest.py build/portable-debug/DaedalusAssetValidator
```

The source delivery workflow additionally regenerates/validates the final clean extraction so fixture metadata cannot silently drift from committed assets.
