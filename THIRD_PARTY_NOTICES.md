# Third-party notices

This Campaign B source snapshot does not vendor or redistribute third-party source code, parser libraries, image libraries, SDK binaries, or sample assets.

The implementation uses separately supplied platform components on Windows:

- Windows SDK headers and import libraries for Win32, COM, Windows Imaging Component, DXGI, and Direct3D 12.
- DirectX Shader Compiler (`dxc.exe`) from a compatible Windows SDK or official standalone DXC distribution.
- Microsoft Visual C++ toolchains for the documented Visual Studio presets.

The glTF importer is project-owned code written against the Khronos glTF 2.0 specification. The specification is a normative reference, not redistributed source code. All committed test fixtures are generated by `tests/assets/generate_fixtures.py`, are self-authored, and are dedicated to CC0-1.0 for redistribution and regression testing.

No NVIDIA SDK, restricted runtime DLL, copyrighted production model, proprietary game asset, Assimp, cgltf, tinygltf, stb, or other third-party implementation is included.
