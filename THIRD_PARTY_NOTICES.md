# Third-party notices

Project Daedalus does not vendor third-party parser or image-decoder source in this archive.

## Platform components

Windows builds use separately supplied Windows SDK components:

- Win32, COM, Windows Imaging Component, DXGI, Direct3D 12, and their headers/import libraries;
- DirectX Shader Compiler (`dxc.exe`) from a compatible Windows SDK or official DXC package;
- Microsoft Visual C++ through the documented Visual Studio presets.

## Portable image-decoder dependencies

Non-Windows portable builds locate and link separately installed:

- **libpng** through CMake `find_package(PNG REQUIRED)`; the closure environment used libpng 1.6.48 under the libpng license.
- **libjpeg** or a compatible libjpeg-turbo implementation through `find_package(JPEG REQUIRED)`; the closure environment used libjpeg ABI 62 supplied by libjpeg-turbo 2.1.5 under its BSD-style/IJG/zlib license set.

These libraries are build-environment dependencies and are not copied into the source archive. Their licenses remain with the system packages/distributions that provide them. The repository does not claim byte-pinned third-party decoder source; instead, `src/assets/ImageDecoder.cpp` isolates the platform decoders behind one project-owned RGBA8 contract and the real fixture corpus is run under both supported compiler configurations. Windows uses WIC through the same structured assets-layer contract. A future dependency-vendoring campaign may freeze decoder source if cross-platform decoder-byte identity becomes a requirement.

## Project-owned importer and fixtures

The glTF importer is project-owned code written against the Khronos glTF 2.0 specification. No Assimp, tinygltf, cgltf, stb, proprietary parser, NVIDIA SDK, restricted runtime DLL, production game asset, or copyrighted model is included.

All controlled assets are generated by `tests/assets/generate_fixtures.py`, are self-authored, and are dedicated to CC0-1.0 as described in `tests/assets/LICENSE.md`.
